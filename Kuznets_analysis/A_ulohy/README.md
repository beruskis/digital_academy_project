# Průvodce složkou A_ulohy

## Styl učení: Samostatná práce (Výzva)

Tento styl je pro tebe pokud:
- Chceš se opravdu naučit psát kód sama
- Máš ráda výzvy a hledání řešení
- Víš, že máš záchrannou síť (řešení) kdykoli potřebuješ

## Postup

1. Otevři **`01_pruzkum_dat_ULOHY.ipynb`**
2. Přečti zadání každé úlohy
3. Napiš vlastní kód do buňky `# TVŮJ KÓD ZDE`
4. Zkontroluj výstup s **očekávaným výsledkem** v zadání
5. Pokud se zasekneš:
   - Nejdříve zkus nápovědy v komentářích
   - Pak se podívej do `01_pruzkum_dat_RESENI.ipynb`
6. Pokračuj s `02_statistika_ekc_ULOHY.ipynb`

## Tipy pro zaseknutí

1. Přečti chybovou hlášku celou — Python ti říká přesně co je špatně
2. Vypiš typ proměnné: `print(type(promenna))`
3. Vypiš sloupce: `print(df.columns.tolist())`
4. Koukni na dokumentaci: napiš `pd.merge?` nebo `help(pd.merge)`
5. Pak teprv koukni do řešení
